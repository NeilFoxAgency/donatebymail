What volunteering looks like here

Useful work, clear boundaries.

Because donated phones can contain personal information and lithium-ion batteries, not every task is appropriate for an informal volunteer project. We will be clear about what a role includes before anyone begins.

  • Never ask a donor for a password, passcode, recovery code, or account credential.
  • Do not represent yourself as authorized to promise donation values, tax treatment, or guaranteed charity proceeds.
  • Hands-on device or donor-data access requires explicit instructions and appropriate safeguards.
  • If a project is not currently useful, we would rather say so than create busywork.
