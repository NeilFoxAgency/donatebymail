# Donate by Mail

Donate by Mail turns unused phones into funding for meaningful causes.

This repository contains the public donation experience, including a phone-value estimator, prepaid mailing-plan flow, data-security guidance, and a printable sample noncash donation acknowledgment.

The production target is Cloudflare Workers Static Assets, with future Cloudflare D1 and R2 services for donation records and issued receipts.

> The estimator is not an appraisal or tax valuation. Official acknowledgments should describe donated property without assigning fair market value and should only be issued after the property is received.
